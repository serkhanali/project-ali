# Use-case сипаттамасы: Жүйеге кіру

| Өріс | Мәні |
| --- | --- |
| Атауы | Жүйеге кіру |
| Актер | Пайдаланушы |
| Қысқаша сипаттама | Пайдаланушы логин мен пароль арқылы жүйеге кіреді |
| Алғы шарт | Пайдаланушы жүйеде тіркелген |
| Нәтиже | Пайдаланушы жүйеге кіріп, басты бет ашылады |
| Байланысты талаптар | FR-1, FR-2, FR-6 |

## Негізгі сценарий

1. Пайдаланушы кіру бетін ашады.
2. Пайдаланушы логин мен парольді енгізеді.
3. Пайдаланушы «Кіру» батырмасын басады.
4. Жүйе енгізілген деректерді тексереді.
5. Деректер дұрыс болса, жүйе басты бетті ашады.

## Баламалы сценарийлер

- **4а. Логин немесе пароль қате.** Жүйе қате туралы хабарлама көрсетіп, пайдаланушыны 2-қадамға қайтарады.
- **2а. Өрістер бос.** Жүйе логин мен парольді толтыру керектігін көрсетеді.
