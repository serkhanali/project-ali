# Талаптар

Бұл құжатта жүйеге қойылатын функционалдық және функционалдық емес талаптар берілген.

## 1. Функционалдық талаптар

| Код | Талап | Басымдығы |
| --- | --- | --- |
| FR-1 | Пайдаланушы логин мен пароль арқылы жүйеге кіре алуы керек | Жоғары |
| FR-2 | Жүйе енгізілген логин мен парольді тексеруі керек | Жоғары |
| FR-3 | Пайдаланушы жаңа деректерді қоса алуы керек | Жоғары |
| FR-4 | Пайдаланушы бар деректерді өзгерте алуы керек | Орташа |
| FR-5 | Пайдаланушы деректер тізімін көре алуы керек | Орташа |
| FR-6 | Деректер қате енгізілсе, жүйе қате туралы хабарлама көрсетуі керек | Жоғары |

## 2. Функционалдық емес талаптар

| Код | Санат | Талап |
| --- | --- | --- |
| NFR-1 | Өнімділік | Жүйенің жауап беру уақыты 3 секундтан аспауы керек |
| NFR-2 | Қолайлылық | Интерфейс қарапайым және түсінікті болуы керек |
| NFR-3 | Қауіпсіздік | Пароль ашық түрде сақталмауы және көрсетілмеуі керек |
| NFR-4 | Сенімділік | Жүйе тұрақты жұмыс істеп, енгізілген деректер жоғалмауы керек |
| NFR-5 | Үйлесімділік | Жүйе заманауи веб-браузерлерде жұмыс істеуі керек |
